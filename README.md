# Palito Launcher · descargas

Launcher de **Coop2D**: instala el juego, lo mantiene actualizado y recoge las opiniones de las pruebas.

## Instalar

1. Entra en **[Releases → Latest](https://github.com/JJJP-Dev/PalitoLauncher-dist/releases/latest)** y descarga
   **PalitoLauncher.exe** (no los archivos «Source code»).
2. Ábrelo. Se copia solo a `%LOCALAPPDATA%\Programs\PalitoLauncher` y crea el acceso «Coop2D» en el menú Inicio.
3. Si Windows muestra «Windows protegió su PC»: **Más información → Ejecutar de todas formas** (el exe no está firmado
   con un certificado de pago).

Una vez instalado se actualiza solo.

Este repositorio lo mantiene una automatización: no contiene código y no acepta issues ni pull requests.
